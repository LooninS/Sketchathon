# Sketchathon

Welcome to **Sketchathon Day 2!** 

Ready to put your Git and GitHub skills to the test?

This repository contains the tasks for Sketchathon Day 2. Each task is designed to help you learn by working with real-world GitHub workflows.

## 📝 How to Participate

1. Visit the **[Issues](https://github.com/LooninS/Sketchthon/issues)** tab.
2. Read the task instructions carefully.
3. Create a branch and complete the assigned task.
4. Commit and push your changes.
5. Open a **[Pull Request](https://github.com/LooninS/Sketchthon/pulls)** against the default branch.
6. Wait for validation and feedback from the maintainers.

## 📌 Important

- Follow the instructions provided in each issue.
- Use the required branch names and file paths.
- Keep your Pull Requests focused on the assigned task.
- Do not modify workflow files or bot configurations unless explicitly instructed.
- Keep your Pull Request open until the task has been reviewed.

## Goal

Learn, experiment, collaborate, and have fun!

**Happy Hacking!**
