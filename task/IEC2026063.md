## Merge Conflict Resolution 🤝

During this challenge, my original introduction was created on my personal branch, while the workshop bot added a competing change to the same file on the main branch.

I integrated both contributions by preserving my original introduction and incorporating the bot's requested sentence:

> The final report must explain how both contributions were integrated.

This demonstrates how merge conflicts can be resolved while keeping the intended contributions from both sides.

**Learning outcome:** I learned how Git merge conflicts happen and why both contributions must be carefully preserved.
